# Contributing to awesome-blockchain-rust

First off, thanks for taking the time to contribute! 🎉

## Adding a New Entry

1. **Fork** this repository
2. **Add your entry** to the appropriate section in `README.md`
3. **Follow the format**: `- [Name](URL) — Brief description`
4. **Alphabetize** within the section
5. **Submit a PR** with a clear title

## Guidelines

- **One entry per PR** — easier to review
- **Include a description** — not just a link
- **Verify the project is active** — no dead links
- **Rust-focused** — projects should use Rust or target Rust ecosystem

## Quality Checks

- [ ] Link is reachable (no 404s)
- [ ] Description is concise (under 80 chars)
- [ ] Entry is in the correct section
- [ ] Alphabetical order maintained
- [ ] No duplicate entries

## Sections

| Section | Content |
|---------|---------|
| Frameworks | Blockchain frameworks built in Rust |
| Protocols | Protocol implementations |
| Tools | CLI tools, SDKs, libraries |
| Smart Contracts | Smart contract platforms/languages |
| DeFi | Decentralized finance projects |
| Mining | Mining software and pools |

## Code of Conduct

Be respectful. No harassment, discrimination, or trolling.
