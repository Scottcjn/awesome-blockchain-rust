# Contributing to Awesome Blockchain Rust

Thank you for your interest in contributing to Awesome Blockchain Rust!

## How to Contribute

1. **Fork** the repository
2. **Clone** your fork
3. **Create** a branch for your changes
4. **Submit** a Pull Request

## Adding Resources

- Ensure the resource is related to Blockchain and Rust
- Follow the existing format
- Add appropriate categories
