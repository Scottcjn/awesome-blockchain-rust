# Contributing to Awesome Blockchain Rust

Thanks for helping build the ultimate resource for Rust blockchain development!

## Quick Start

1. Fork this repository
2. Add your project to the appropriate category
3. Open a Pull Request

## Adding a Project

### Format

```markdown
- [Project Name](https://github.com/link).
  One-line description of the project.
```

Keep it simple:
- Project name as link
- Period after link
- One-line description
- No extra formatting

## Categories

- **Blockchains** - Full blockchain implementations
- **Blockchain Frameworks** - SDKs for building chains
- **Cross-Chain** - Interoperability solutions
- **Virtual Machines** - Smart contract execution
- **Consensus** - Consensus algorithms
- **P2P Network** - Networking libraries
- **Cryptography** - Crypto primitives
- **Layer2** - Scaling solutions
- **Dapps** - Decentralized applications
- **Other** - Everything else

## Quality Criteria

**Accepted:**
- ✅ Written in Rust (or Rust bindings)
- ✅ Active development or stable release
- ✅ Public repository
- ✅ Relevant to blockchain/DLT

**Not accepted:**
- ❌ Non-Rust projects (unless Rust bindings)
- ❌ Abandoned projects (2+ years inactive)
- ❌ Private/closed-source code
- ❌ Unrelated to blockchain

## Pull Request Checklist

- [ ] Project is written in Rust or provides Rust bindings
- [ ] Added to correct category
- [ ] Description is one line
- [ ] Link works and points to repo
- [ ] Alphabetically sorted within category
- [ ] Not a duplicate

## Style Guide

- **Alphabetical order** within each category
- **One line per entry** - no multi-line descriptions
- **Period after link** before description
- **No badges or icons** in entries

## Updates

You can also:
- Fix broken links
- Update stale descriptions
- Suggest new categories via issue
