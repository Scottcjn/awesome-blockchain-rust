# Contributing to Awesome Blockchain Rust

Thanks for helping improve this list of Rust projects used to build blockchains, wallets, protocols, and decentralized applications. Contributions should help Rust developers find useful, maintained components faster.

## What to Add

- Rust blockchain clients, frameworks, virtual machines, consensus libraries, networking libraries, cryptography crates, layer 2 tooling, dapp infrastructure, and developer tools.
- Projects with a public source repository, clear documentation, and enough activity or adoption to be useful to builders.
- Resources that fit an existing section such as blockchains, blockchain frameworks, cross-chain, virtual machines, consensus, P2P, cryptography, layer 2, dapps, or other.

## Entry Format

Match the existing Markdown style:

```markdown
- [Project Name](https://github.com/org/repo).
  Short factual description.
```

Keep descriptions short, factual, and focused on what the Rust project provides. Mention the protocol, runtime, crate, or network role when it helps readers compare similar entries.

## Pull Request Checklist

- Confirm the project is implemented primarily in Rust or provides Rust-first blockchain tooling.
- Put the entry in the most specific matching section.
- Check that every added link resolves and points to the intended repository or documentation.
- Avoid duplicate entries already listed under another section.
- Keep the Markdown format consistent with nearby entries.

## Good Contributions

- Add a missing Rust client, framework, crate, or developer tool.
- Update a project that moved repositories, renamed, or changed documentation.
- Improve a stale description with a more accurate one-sentence summary.
- Move an entry to a better section when the category is inaccurate.

## Not a Fit

- Token promotion, price speculation, referral links, or project marketing.
- Projects without public source code or enough documentation for readers to evaluate them.
- General blockchain resources that do not have a Rust implementation or Rust developer focus.
